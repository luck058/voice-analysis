# Task: pitch_trace_view

## Goal

Implement a scrolling pitch-trace model that displays voice pitch over time on a musical note grid, similar to singing trainers. The model should maintain recent pitch points, map them to canvas coordinates, and provide segments for drawing and grid lines for reference.

## Requirements

1. Constructor must accept width, height, and optional windowSec (default 8), minMidi (default 40/E2), maxMidi (default 84/C6)
2. add(timeSec, hz) must record a point (hz null for unvoiced) and discard points older than windowSec from the newest point
3. xForTime(timeSec, nowSec) must map nowSec to x=width, nowSec-windowSec to x=0, linearly
4. yForMidi(midi) must map maxMidi to y=0, minMidi to y=height, linearly in fractional MIDI, clamped to [0, height]
5. segments(nowSec) must return arrays of {x,y} points where consecutive voiced points form segments, unvoiced points or gaps >0.1s start new segments, single-point segments are kept
6. gridLines() must return one entry per integer MIDI from minMidi to maxMidi with y coordinate, MIDI number, label from noteName, and isC flag for C notes
7. Must use hzToMidi from src/music/notes.ts to convert Hz to MIDI for y coordinate calculation

## Files in scope

- `src/views/pitchTrace.ts`

## Context

The notes module (src/music/notes.ts) is already implemented and verified. It exports hzToMidi and noteName functions. Follow TypeScript conventions: named exports only, explicit types, no DOM dependencies. Invalid input should throw RangeError with parameter name. 'No answer' (unvoiced) is null, never NaN or exception.

## How to run the tests

Run the tests before finishing. The harness independently re-runs them and
rejects the task if its trajectory shows no real test run.

The test tooling is installed for you before this session starts, by
`.openhands/setup.sh`. Normally you only need the run command below.
Do not reinstall the project's dependencies yourself (`npm ci`, `npm install`,
`pip install -r ...`): the test tooling is not in the project's manifest, so
a reinstall removes it.

    npx --no -- jest --ci
