# Task: pitch_trace_view

## Goal

Implement a scrolling pitch-trace model that displays voice pitch over time on a musical note grid, similar to singing trainers. The model should maintain recent pitch points, map them to canvas coordinates, and provide segments for drawing and grid lines for reference.

## Requirements

1. Constructor must accept width, height, and optional windowSec (default 8), minMidi (default 40/E2), maxMidi (default 84/C6).
2. add(timeSec, hz) must record a point (hz null for unvoiced) and discard points older than windowSec relative to the newest point.
3. xForTime(timeSec, nowSec) must map time to x coordinate: nowSec at x = width, nowSec - windowSec at x = 0, linear interpolation.
4. yForMidi(midi) must map MIDI to y coordinate: maxMidi at y = 0, minMidi at y = height, linear interpolation, clamped to [0, height].
5. segments(nowSec) must return an array of segments, where each segment is an array of {x, y} points. Consecutive voiced points form a segment; an unvoiced point or a gap > 0.1 seconds starts a new segment. Single-point segments are kept.
6. gridLines() must return an array of objects with y, midi, label, isC for each integer MIDI from minMidi to maxMidi, where label comes from noteName and isC is true for C notes.
7. 440 Hz must map to yForMidi(69) (A4).

## Files in scope

- `src/views/pitchTrace.ts`

## Context

The notes module (src/music/notes.ts) is already implemented and verified. It exports hzToMidi and noteName functions. Use ES module syntax, explicit types, and throw RangeError for invalid inputs. The pitch trace model is pure TypeScript with no DOM dependencies.

rejects the task if its trajectory shows no real test run.

`.openhands/setup.sh`. Normally you only need the run command below.
