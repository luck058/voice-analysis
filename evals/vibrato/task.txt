# Task: vibrato

## Goal

Implement vibrato detection from a pitch track, returning the rate in Hz and extent in cents for sustained oscillations between 3-9 Hz with sufficient amplitude, or null when no vibrato is detected.

## Requirements

1. detectVibrato must accept a track of PitchPoint objects in time order and return a Vibrato object with rateHz and extentCents properties, or null
2. Points with gaps >0.1s must split the track; use the longest contiguous run that spans at least 1.0s and has at least 20 points
3. Remove a least-squares linear trend from the detrended run before analysis
4. rateHz must be computed from the dominant periodicity of the detrended run (e.g., via zero crossings or autocorrelation peak after resampling to 100 points per second)
5. extentCents must be half the mean peak-to-trough excursion of the detrended run
6. Return null when rateHz is outside [minRateHz, maxRateHz] or extentCents < minExtentCents
7. Default options: minRateHz = 3, maxRateHz = 9, minExtentCents = 10

## Files in scope

- `src/analysis/vibrato.ts`

## Context

This is a new feature with no dependencies. Follow TypeScript conventions: named exports only, explicit types, and throw RangeError for invalid input. PitchPoint interface has timeSec and cents properties. The implementation must be pure (no DOM, no timers, no Math.random).
