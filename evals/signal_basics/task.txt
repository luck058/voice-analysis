# Task: signal_basics

## Goal

Implement deterministic signal generators for testing, FFT spectrum analysis, and level measurement functions. These are foundational DSP modules that will be used by all subsequent audio analysis components.

## Requirements

1. sine(hz, sampleRate, length, amplitude, phase) returns a Float32Array of a sine wave with given parameters
2. harmonicTone(hz, sampleRate, length, harmonics, amplitude) returns a band-limited sawtooth wave with harmonics up to Nyquist, scaled to given amplitude
3. vibratoTone(hz, rateHz, extentCents, sampleRate, length, amplitude) returns a sine with frequency modulation generated by phase accumulation
4. whiteNoise(length, amplitude, seed) returns uniform noise in [-amplitude, amplitude] using mulberry32 PRNG
5. pulseTrain(periodsSec, sampleRate, amplitudes) returns a series of raised-cosine pulses at specified times
6. resonate(signal, sampleRate, formants) applies cascade of Klatt two-pole resonators to simulate formants
7. mix(a, b) returns sample-wise sum of two signals
8. scaleToRms(signal, dbfs) returns a copy scaled to target RMS level in dBFS
9. hannWindow(size) returns symmetric Hann window coefficients
10. fft(re, im) performs in-place radix-2 FFT, throws RangeError for invalid lengths
11. magnitudeSpectrumDb(frame) returns dB magnitude spectrum with Hann window, normalized, floored at -120 dB
12. binFrequency(bin, sampleRate, frameSize) returns frequency in Hz for given FFT bin
13. rmsDbfs(frame) returns RMS level in dBFS, -120 for silence
14. peakDbfs(frame) returns peak level in dBFS, -120 for silence

## Files in scope

- `src/testing/synth.ts`
- `src/dsp/fft.ts`
- `src/dsp/level.ts`

## Context

Follow TypeScript conventions: ES module syntax, explicit types on all exports. Audio is Float32Array in [-1, 1]. Invalid input throws RangeError with descriptive message. 'No answer' (silence) returns null, never NaN. These are pure modules: no DOM, no Web Audio, no timers, no Math.random. Use Float64Array for FFT real/imaginary parts as specified. For whiteNoise, implement mulberry32 PRNG: function mulberry32(a) { return function() { a |= 0; a = a + 0x6D2B79F5 | 0; let t = Math.imul(a ^ a >>> 15, 1 | a); t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t; return ((t ^ t >>> 14) >>> 0) / 4294967296; }; }

## How to run the tests

Run the tests before finishing. The harness independently re-runs them and
rejects the task if its trajectory shows no real test run.

The test tooling is installed for you before this session starts, by
`.openhands/setup.sh`. Normally you only need the run command below.
Do not reinstall the project's dependencies yourself (`npm ci`, `npm install`,
`pip install -r ...`): the test tooling is not in the project's manifest, so
a reinstall removes it.

### Commands

Run the tests:

    npx --no -- jest --ci

If that reports the test runner is missing, the pre-install failed.
Re-run it yourself, passing the terminal tool's `timeout` parameter as at
least 900 seconds (otherwise the command is
paused after 30 seconds with no new output and reports exit code -1 while
it is still running):
