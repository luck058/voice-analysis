# Task: signal_basics

## Goal

Implement deterministic signal generators for testing, FFT operations for spectrum analysis, and level measurement functions. These are foundational DSP modules that will be used by all subsequent audio analysis components.

## Requirements

1. sine() must generate a pure sine wave at the specified frequency, amplitude, and phase
2. harmonicTone() must generate a band-limited sawtooth wave with harmonics up to Nyquist limit, scaled to the given amplitude
3. vibratoTone() must generate a sine wave with frequency modulation using phase accumulation (no discontinuities)
4. whiteNoise() must generate reproducible uniform noise using mulberry32 PRNG with the given seed
5. pulseTrain() must generate pulses at specified time intervals with raised-cosine shape
6. resonate() must apply formant filtering using Klatt two-pole resonators in cascade
7. mix() must sum two signals sample-wise, handling different lengths
8. scaleToRms() must scale a signal to achieve the specified RMS level in dBFS
9. hannWindow() must generate a symmetric Hann window of the given size
10. fft() must perform in-place radix-2 FFT on complex arrays, throwing RangeError for invalid inputs
11. magnitudeSpectrumDb() must compute dB magnitude spectrum with Hann window and proper normalization, flooring at -120 dB
12. binFrequency() must compute frequency for a given FFT bin
13. rmsDbfs() must compute RMS level in dBFS, returning -120 for silence
14. peakDbfs() must compute peak level in dBFS, returning -120 for silence

## Files in scope

- `src/testing/synth.ts`
- `src/dsp/fft.ts`
- `src/dsp/level.ts`

## Context

All modules must be pure TypeScript with no DOM or browser APIs. Use Float32Array for audio signals. Follow the exact interface specifications from architecture.md. Invalid inputs should throw RangeError with descriptive messages. 'No answer' cases (like silence) should return null or appropriate default values, never exceptions or NaN. All functions must be deterministic and testable.
