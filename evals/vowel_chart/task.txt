# Task: vowel_chart

## Goal

Implement the vowel chart module that provides reference vowel data, converts frequencies to Bark scale, calculates chart positions, and finds the nearest reference vowel for given formant frequencies. This enables visualizing formant measurements on a vowel chart with proper orientation (front vowels on the left, open vowels at the bottom).

## Requirements

1. Export REFERENCE_VOWELS as a Record with 'men' and 'women' keys, each containing an array of ReferenceVowel objects with the exact symbol, example word, F1, and F2 values specified in the todo details.
2. Implement hzToBark(hz: number): number using the Zwicker formula: 13*atan(0.00076*hz) + 3.5*atan((hz/7500)^2).
3. Implement chartPosition(f1: number, f2: number, width: number, height: number): { x: number; y: number } with the specified orientation: x = width * (bark(3000) - bark(f2)) / (bark(3000) - bark(500)); y = height * (bark(f1) - bark(200)) / (bark(1000) - bark(200)); clamp both x and y to [0, width] and [0, height] respectively.
4. Implement nearestVowel(f1: number, f2: number, set: 'men' | 'women'): { vowel: ReferenceVowel; distanceBark: number } using Euclidean distance on (bark(f1), bark(f2)) coordinates.
5. Implement referenceSetFor(medianF0Hz: number): 'men' | 'women' returning 'men' for medianF0Hz < 165 Hz, else 'women'.
