# Task: voice_quality

## Goal

Implement the measureVoiceQuality function that computes voice quality metrics (jitter, shimmer, and harmonics-to-noise ratio) from audio samples given a fundamental frequency. This enables the system to report voice-quality measures when the input has been voiced for at least half a second.

## Requirements

1. measureVoiceQuality must compute jitterPercent using Praat's 'jitter (local)' formula: 100 * mean(|T_i - T_{i+1}|) / mean(T), where T_i are periods between consecutive cycle marks
2. measureVoiceQuality must compute shimmerPercent using Praat's 'shimmer (local)' formula: 100 * mean(|A_i - A_{i+1}|) / mean(A), where A_i are amplitudes at cycle marks
3. measureVoiceQuality must compute hnrDb as 10 * log10(r / (1 - r)), where r is the largest normalized autocorrelation over lags within +/-10% of sampleRate / f0Hz, clamped to [0.0001, 0.9999]
4. measureVoiceQuality must find cycle marks by searching for the largest absolute sample within +/-20% of each expected period around where the next cycle is expected, refined with parabolic interpolation
5. measureVoiceQuality must return null when there are fewer than 10 complete cycles, when rmsDbfs is below SILENCE_DBFS (-60), or when f0Hz is outside [PITCH_MIN_HZ, PITCH_MAX_HZ]
6. measureVoiceQuality must never return NaN for any valid input

## Files in scope

- `src/dsp/voiceQuality.ts`

## Context

Use ES module syntax (import/export). Type every exported function's parameters and return value explicitly. The signal_basics dependency is already implemented and verified: src/dsp/fft.ts, src/dsp/level.ts, and src/testing/synth.ts are available with working code. Use constants from src/config.ts: DEFAULT_SAMPLE_RATE, FRAME_SIZE, HOP_SIZE, PITCH_MIN_HZ, PITCH_MAX_HZ, A4_HZ, SILENCE_DBFS. The VoiceQuality interface is { jitterPercent: number; shimmerPercent: number; hnrDb: number }. Invalid input should throw RangeError with a message naming the parameter. 'No answer' (silence, unvoiced audio) is null, never an exception and never NaN.

rejects the task if its trajectory shows no real test run.
