# Task: notes

## Goal

Implement the music theory functions that convert between frequency, MIDI note numbers, note names, and cents. These functions will be used by the pitch detector to display the musical note information for the user's voice pitch.

## Requirements

1. hzToMidi(hz, a4) returns fractional MIDI number: 69 + 12*log2(hz/a4)
2. midiToHz(midi, a4) returns frequency: a4 * 2^((midi - 69)/12)
3. noteName(midi) returns string in scientific pitch notation with sharps only (e.g., 60 -> 'C4', 61 -> 'C#4', 69 -> 'A4')
4. hzToNote(hz, a4) returns NoteInfo with nearest integer MIDI, note name without octave, octave number, and cents in [-50, 50)
5. hzToMidi and hzToNote throw RangeError when hz is not a finite number > 0
6. midiToHz(hzToMidi(x)) round-trips within floating-point precision

## Files in scope

- `src/music/notes.ts`

## Context

Follow TypeScript conventions: named exports only, explicit types. Use ES module syntax (import/export). The config.ts file exists with A4_HZ constant. Invalid input should throw RangeError with a message naming the parameter. 'No answer' cases (like silence) are handled elsewhere as null, not in these functions.
